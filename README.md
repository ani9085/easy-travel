## 현재 작업 상태 (2026-10-31)

**현재 main**: 첫 화면에서 역할을 고르면 **부모님 화면(`/traveler`)** 과 **보호자 화면(`/guardian`)** 으로 나뉩니다. 부모님도 여행지·기간·인원·취향을 직접 정할 수 있고, 보호자 화면은 현황·계획·항공 가격·일정/숙소 추천·확정 일정·설정을 메뉴별 화면으로 나눕니다. 새 여행은 빈 계획에서 시작하며, 저장소에 남은 이전 Mock 장소·항공 후보는 실제 계획으로 읽지 않습니다.

**P0**:

P0 안정화를 브랜치 `claude/p0-hardening`에서 마쳤습니다(main 병합 전).

- 계획·여행 중·귀가 후가 **하나의 여행 데이터(Trip)** 를 씁니다. 저장 위치는 이 기기의 `localStorage`(`easy-travel:trip`) 한 곳이고, 예전 저장소에 있던 값은 자동으로 옮깁니다.
- 목적지에 따라 자주 쓰는 말·통화·시간대가 바뀝니다(프랑스·일본·태국·베트남, 그 밖의 곳은 영어).
- `/api/ai`는 같은 출처 확인, 가족 접속 코드(선택), 요청 횟수 제한, 20초 타임아웃을 거칩니다.
- Next.js 16 / React 19로 올렸습니다(14.x 지원 종료·취약점 대응).

항공 가격은 `DUFFEL_ACCESS_TOKEN`이 설정된 경우에만 실제 공급자 결과를 표시합니다. 키가 없으면 가짜 후보를 만들지 않습니다. 항공 예약·결제는 앱이 대신하지 않으며, 가격 감시는 APK의 Android 백그라운드 작업에서 하루 2회 실행하는 단계로 설계했습니다.

## 현재 MVP

- Google Maps URL(API 키 불필요)로 장소 검색·길찾기·이동수단(걸어서/대중교통/자동차) 선택
- 현지 통화↔원화 환전 — 데모 값·직접 입력·ECB 기준환율(Frankfurter) 조회, 출처·조회 시각·마지막 성공값 표시(참고용). 목적지 통화를 자동으로 고릅니다.
- 목적지 언어의 자주 쓰는 말 + OpenRouter 자유 번역(한국어→현지어)
- 사진으로 장소 후보 확인 — 전송 전 안내, 1280px 축소·EXIF 제거, 서버 크기 제한, 실패 시 직접 입력
- 여행 전 계획 — 부모님·보호자 공통 입력, 날짜 검증, 공항 코드 기반 실제 항공 조회 준비, 목표 금액과 하루 2회 가격 확인 조건 저장
- OpenRouter 일정 계획 — 외부 예약을 완료로 표시한 뒤 AI가 일정·숙소 후보 지역 초안을 만들고, 사용자가 수정·확정한 장소만 일정에 등록
- 여행계획서 텍스트에서 장소 후보 미리보기 → 선택한 장소만 일정에 등록
- 목적지 시간대 기준 “출발까지 N일 / 여행 N일째” 표시와 오늘의 다음 일정
- 수동 안부 기록과 SOS 기록 데모(이 기기에만 기록, 보호자 알림 미연결)
- 긴급전화 — 가족이 직접 넣은 현지 긴급번호와 외교부 영사콜센터, 확인 단계를 거쳐서만 연결
- 가족 공유는 **준비 중**입니다(링크·서버 공유 없음).

## 실행

```bash
npm install
npm run dev
```

검사(테스트는 TypeScript를 그대로 실행하므로 Node 22.18 이상 필요):

```bash
npm run check
npm run build
```

환경변수(로컬 `.env.local` 또는 Vercel 프로젝트 설정에만 넣습니다):

```text
OPENROUTER_API_KEY=...
OPENROUTER_MODEL=...
OPENROUTER_VISION_MODEL=...      # 사진 분석용(이미지 입력 지원 모델). 비우면 OPENROUTER_MODEL 사용
OPENROUTER_SITE_URL=https://easy-travel-dosl.vercel.app   # 비우면 요청 주소를 씀
EASY_TRAVEL_ACCESS_CODE=...      # 설정하면 번역·사진·일정 AI에 이 코드가 필요. 가족에게만 알려 주세요
DUFFEL_ACCESS_TOKEN=...          # 실제 항공 조회용 서버 Secret. 없으면 항공 후보를 표시하지 않음
EASY_TRAVEL_APP_ORIGINS=capacitor://localhost  # APK WebView Origin을 허용할 때만 추가
```

공개 배포 전에 할 일: OpenRouter 대시보드에서 키 사용 한도를 걸고, 필요하면 Duffel 토큰을 추가하고, `EASY_TRAVEL_ACCESS_CODE`를 설정한 뒤 Vercel 배포 보호를 끕니다. 부모님 기기에서는 ‘여행 설정 → AI 접속 코드’에 코드를 한 번 넣으면 됩니다. Capacitor Android debug APK 골격과 빌드 명령은 [네이티브 APK 계획](./docs/NATIVE_APK_PLAN_KO.md)을 참고하세요. 현재 debug APK는 `CAPACITOR_SERVER_URL`로 지정한 웹 서버를 사용하므로 운영 APK는 공개 운영 URL로 다시 빌드해야 합니다.

## 안전 기능의 한계

이 MVP의 안전 관련 기능은 데모이며 긴급 구조를 대신하지 않습니다.

- **SOS·안부는 기록만 합니다.** 버튼을 누른 시각·위치를 이 기기 화면에 남길 뿐, 보호자·구조기관에 알림이나 위치를 보내지 않습니다. 자동·주기적 위치 추적도 없습니다.
- **현지 긴급번호는 가족이 직접 넣습니다.** 나라마다 긴급번호가 달라 앱이 번호를 정하지 않습니다(입력란의 `112`는 예시일 뿐). 출발 전에 여행 국가의 긴급번호를 확인해 "가족 여행 설정"에 넣어 주세요. 번호가 없으면 전화 버튼이 설정으로 안내하며, 앱은 입력된 번호가 맞는지 검증하지 않습니다. 값은 이 기기의 여행 데이터(`easy-travel:trip`)에만 남습니다.
- **전화는 확인 후에만 겁니다.** 전화 버튼을 누르면 번호를 보여주는 확인 단계가 뜨고, "전화 걸기"를 눌러야 `tel:` 링크가 열립니다.
- **영사콜센터** `+82-2-3210-0404`(`tel:+82232100404`)는 해외에서 거는 한국 번호라 국제전화·로밍 요금이 나올 수 있습니다. 번호 출처: 외교부 해외안전여행 <https://0404.go.kr/> — 배포 전에 다시 확인하세요.
- **`tel:` 링크는 기기에 따라 동작하지 않을 수 있습니다.** 전화 기능이 없는 PC·태블릿, 유심이 없거나 통신이 안 되는 상황에서는 아무 일도 일어나지 않을 수 있어, 확인 단계에 번호를 크게 보여줍니다.

가격·위치·AI 결과는 참고용입니다. 이 MVP는 예약·결제·긴급 구조를 대신하지 않습니다.
