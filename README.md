## 현재 작업 상태 (2026-10-31)

여행 중 보조 기능에 더해 **여행 전 계획 화면**을 추가했습니다. 목적지·출발지·기간·인원·예산·여행 선호를 입력하면 데모 항공권 후보, 기간에 맞춘 추천 일정 요약, 예상 비용을 볼 수 있고 계획과 가격 모니터링 상태를 이 기기에 저장할 수 있습니다.

항공권 후보와 가격 모니터링은 아직 실제 공급자 API·예약·알림에 연결되지 않은 데모입니다. 실제 최저가를 보장하지 않으며, 현재 저장 방식은 브라우저 `localStorage`입니다. 다음 담당자는 먼저 [CLAUDE_HANDOFF_KO.md](./CLAUDE_HANDOFF_KO.md)를 읽고 이 경계를 유지한 채 실제 연동을 단계적으로 진행해 주세요.

## 현재 MVP

가족이 부모님의 해외여행을 함께 준비하고 확인하는 웹 MVP입니다.

- Google Maps URL(API 키 불필요)로 장소 검색·길찾기·이동수단(걸어서/대중교통/자동차) 선택
- 현지 통화·원화 환전 계산 — 데모 값·직접 입력·ECB 기준환율(Frankfurter) 조회, 출처·조회 시각·마지막 성공값 표시 (참고용)
- 자주 쓰는 말과 OpenRouter 기반 통역 경계
- 사진으로 장소 확인하는 AI 경계 — 전송 전 안내·확인, 1280px 축소·EXIF 제거, 서버 크기 제한, 실패 시 직접 입력
- 여행계획서 텍스트에서 장소 후보 미리보기 → 선택한 장소만 일정에 등록
- 가족 코드 기반 공유 링크 데모
- 수동 안부 기록과 SOS 기록 데모 (이 기기에만 기록, 보호자 푸시 미연결)
- 긴급전화 — 가족이 직접 넣은 현지 긴급번호와 외교부 영사콜센터, 누른 뒤 확인 단계를 거쳐서만 연결

현재는 외부 키 없이도 데모 모드로 실행됩니다. 실제 AI 기능은 서버에서만 `OPENROUTER_API_KEY`를 읽도록 구성했습니다.

## 실행

```bash
npm install
npm run dev
```

선택 환경변수:

```text
OPENROUTER_API_KEY=...
OPENROUTER_MODEL=...
OPENROUTER_VISION_MODEL=...   # 사진 분석용(이미지 입력 지원 모델). 비우면 OPENROUTER_MODEL 사용
OPENROUTER_SITE_URL=http://localhost:3000
```

## 안전 기능의 한계

이 MVP의 안전 관련 기능은 데모이며 긴급 구조를 대신하지 않습니다.

- **SOS·안부는 기록만 합니다.** 버튼을 누른 시각·위치를 이 기기 화면(`localStorage`)에 남길 뿐, 보호자·구조기관에 알림이나 위치를 보내지 않습니다. 자동·주기적 위치 추적도 없습니다.
- **현지 긴급번호는 가족이 직접 넣습니다.** 나라마다 긴급번호가 달라 앱이 번호를 정하지 않습니다(입력란의 `112`는 예시일 뿐). 출발 전에 여행 국가의 긴급번호를 확인해 "가족 여행 설정"에 넣어 주세요. 번호가 없으면 전화 버튼이 설정으로 안내하며, 앱은 입력된 번호가 맞는지 검증하지 않습니다. 값은 이 기기의 `easy-travel-demo` 저장소에만 남습니다.
- **전화는 확인 후에만 겁니다.** 전화 버튼을 누르면 번호를 보여주는 확인 단계가 뜨고, "전화 걸기"를 눌러야 `tel:` 링크가 열립니다.
- **영사콜센터** `+82-2-3210-0404`(`tel:+82232100404`)는 해외에서 거는 한국 번호라 국제전화·로밍 요금이 나올 수 있습니다. 번호 출처: 외교부 해외안전여행 <https://0404.go.kr/> — 배포 전에 다시 확인하세요.
- **`tel:` 링크는 기기에 따라 동작하지 않을 수 있습니다.** 전화 기능이 없는 PC·태블릿, 유심이 없거나 통신이 안 되는 상황에서는 아무 일도 일어나지 않을 수 있어, 확인 단계에 번호를 크게 보여줍니다.

가격·위치·AI 결과는 참고용입니다. 이 MVP는 예약·결제·긴급 구조를 대신하지 않습니다.
