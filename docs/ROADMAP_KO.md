# easy-travel 로드맵

> 원칙: 의존성이 있는 순서대로, 작은 PR 단위로 진행합니다. 비용·계약·개인정보가 걸린 연동은 비교안과 질문을 먼저 올리고 승인을 받습니다.

## 2026-10-31 현재 반영분

- 새 설치는 Mock 여행이 아닌 빈 여행 계획에서 시작합니다. 기존 저장소의 `source: demo` 장소와 `dataMode: mock` 항공 후보도 실제 계획으로 복원하지 않습니다.
- 부모님(`/traveler`)도 여행지·날짜·인원·예산·취향을 직접 입력할 수 있습니다.
- 보호자(`/guardian`)는 `현황 / 여행 계획 / 항공 가격 / 일정·숙소 추천 / 확정 일정 / 설정` 메뉴를 화면별로 사용합니다.
- OpenRouter `trip_plan` 작업은 JSON 결과를 서버에서 검증하고, 사용자가 수정·확정한 장소만 일정에 저장합니다.
- Duffel 항공 조회 어댑터는 `DUFFEL_ACCESS_TOKEN`이 있을 때만 실행됩니다. 가격 감시 조건은 하루 2회로 저장되며 실제 백그라운드 실행은 Android APK의 WorkManager 단계입니다.
- APK 전환의 상세 경계는 [NATIVE_APK_PLAN_KO.md](./NATIVE_APK_PLAN_KO.md)에서 관리합니다.

## 2주 단기 목표 제안

P1의 PR-05 ~ PR-08(화면 분리, 텍스트 양방향 통역, 일정 진행·숙소 도착 기록, Mock 계획 품질)을 우선합니다. 실제 공급자 키와 약관이 확인되면 P3을 따로 일정에 잡습니다. 2주는 진행 속도를 모르는 상태의 추정이며, 일정을 보장하지 않습니다.

## 배포 전 사용자 작업

1. OpenRouter 대시보드에서 이 키의 사용 한도(credit limit)를 설정합니다.
2. P0 병합을 승인하면 Vercel 환경변수에 `EASY_TRAVEL_ACCESS_CODE`(가족 공유 코드)와 `OPENROUTER_SITE_URL=https://easy-travel-dosl.vercel.app`을 넣습니다.
3. 그다음 Vercel Authentication을 끄고, 부모님 기기의 ‘가족 여행 설정’에 접속 코드를 입력합니다.
